# OrgChartGenerator

Define organizational structure in simple YAML files and draw diagrams.

Features
* an organization contains one or more teams
* a team may contain employees and nested teams
* a team has a name and optionally a description
* the names of nested child teams are unique 
* 
* an employee has a name, an email address and list of teams he/she is member of
* format of the email address: <first_name>.<last_name>[number_to_make_unique]@<company_name>.<company_toplevel_domain>
